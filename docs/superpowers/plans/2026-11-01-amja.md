# 바닷가 암자(amja) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 폰 브라우저용 공개 3D 공간. 바다를 내려다보는 절벽 암자에서 3인칭으로 걷고, 난간에 기대고, 관세음보살 앞에서 합장·절하고, 다른 사람들과 말없이 같이 있는다.

**Architecture:** 빌드 없는 정적 사이트다(같이산과 같은 방식: ES 모듈 + CDN, `firebase-config.js`의 apiKey가 비면 혼자 모드). 계산은 순수 모듈(`src/logic/*`)에 두고 `node --test`로 검증한다. 3D(`src/scene/*`), 소리(`src/audio.js`), 접속(`src/net/*`)은 그 계산을 가져다 쓴다. 실시간 접속은 Firebase Realtime Database를 쓴다. 위치를 계속 보내지 않고 "어디서 어디로 언제 출발했는지"만 보내면, 받는 쪽이 걸음을 계산해서 그린다.

**Tech Stack:** Three.js 0.170.0 (jsdelivr importmap), Firebase JS SDK 11.10.0 (gstatic, 같이산과 동일), Firebase Realtime Database + 익명 인증, Web Audio API, Node 24 내장 테스트 러너, GitHub Pages.

## Review Focus

1. **바다나 난간 밖을 눌렀을 때:** 절벽 밖으로 걸어 나가면 안 된다. 난간 너머(바다 포함)를 누르면 가장 가까운 난간 자리로 가서 기대고, 건물이나 불상 받침 안을 누르면 가장 가까운 걸을 수 있는 지점으로 간다. → Task 1 `clampToWalkable`, `resolveTap` 테스트.
2. **폰 화면이 꺼지거나 다른 탭으로 갔다 왔을 때:** iOS에서는 연결 끊김 처리(onDisconnect)가 늦게 실행될 수 있다. 그래서 남들 화면에 유령 캐릭터가 남으면 안 되고, 돌아왔을 때 소리가 조용히 멈춰 있으면 안 된다. → Task 6 `peersFromSnapshot` 오래된 접속 정보 필터 테스트. Task 4는 돌아왔을 때 "눌러서 소리 다시 켜기" 한 줄을 띄운다.
3. **Firebase가 설정되지 않았거나 연결이 실패했을 때:** 걷기, 기대기, 소리는 그대로 되어야 하고, 인원 줄만 숨긴다. → Task 6 `createPresence` 혼자 모드 테스트.
4. **기기 시계가 다른 나라 시간대로 되어 있을 때:** 하늘색은 한국 시간 기준이어야 한다. → Task 2 테스트는 UTC 기준 Date를 넣어 확인한다.
5. **불경 소리가 파도 소리를 덮는 경우:** 어느 위치에서도 불경 크기는 0.6을 넘지 않고, 난간에서는 파도의 1/3 이하여야 한다. → Task 4 `layerGains` 테스트.

### Task 2: 한국 시간 하늘

**Files:**

**Interfaces:**

  - `skyAt(date: Date) -> { phase: "dawn"|"day"|"dusk"|"night", sunElevation: number /*도*/, sky: [r,g,b], horizon: [r,g,b], sea: [r,g,b], sun: [r,g,b], light: number /*0..1*/ }`
  - phase 경계: dawn = 해돋이 ±40분, dusk = 해넘이 ±40분, 그 사이가 day, 나머지가 night. 색은 경계 근처에서 선형으로 섞어서 갑자기 바뀌지 않게 한다.

- [ ] **Step 1: 실패하는 테스트를 쓴다** (Date는 모두 UTC로 만든다)
- `sunTimesKST(new Date("2026-06-21T03:00:00Z"))`: sunrise 5:10 ±5분(310 ±5), sunset 19:32 ±5분(1172 ±5)
- `sunTimesKST(new Date("2026-12-21T03:00:00Z"))`: sunrise 7:32 ±5분, sunset 17:18 ±5분
- `skyAt(new Date("2026-06-21T03:00:00Z")).phase === "day"` (한국 정오)
- `skyAt(new Date("2026-06-21T14:00:00Z")).phase === "night"` (한국 23시)
- 2026-06-21 한국 19:32 (`"2026-06-21T10:32:00Z"`) → `"dusk"`
- 한국 23:59와 다음 날 00:01 사이에 sky 색 차이가 성분마다 0.02 이하다(날짜가 바뀌어도 튀지 않음)
- 모든 색 성분은 0..1 범위다
